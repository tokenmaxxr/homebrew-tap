# homebrew-tap

Homebrew tap for [tokenmaxxr](https://github.com/tokenmaxxr)'s tools.

## Casks

### [Hammertunes](https://github.com/tokenmaxxr/Hammertunes.spoon)

Menubar now-playing pill for Hammerspoon. Spotify is well tested; Apple Music
is in beta, with only basic functionality tested so far.

```sh
brew install --cask tokenmaxxr/tap/hammertunes
```
